# KippyAI Sites landing page

Hebrew RTL early-access landing page for KippyAI. The page follows the unified
product direction (parental controls plus WhatsApp safety) and the approved
Calm Signal palette while avoiding claims that have not passed the product
release gate.

The site does not collect or persist visitor data. Early-access and login CTAs
hand off to the existing KippyAI application on `www.kippyai.com`.

## Local checks

- `npm run build`
- `npm test`
- `npm run lint`
