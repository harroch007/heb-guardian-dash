# KippyAI — נכסים ראשוניים

## Logo concepts

- `kippyai-signal-k-concept.svg` — סמל וקטורי ראשוני.
- `kippyai-lockup-concept.svg` — lockup אופקי עם wordmark.
- `kippyai-brand-board.svg` — לוח כיוון צבעוני וקופי.

הקבצים הם קונספטים לבחירת כיוון. הטקסט ב־lockup עדיין חי ואינו outlines. אין להחליף באמצעותם את נכסי המוצר לפני דיוק, בדיקת סימן מסחר ואישור.

## Usage

- אין להוסיף glow ללוגו.
- אין להשתמש בלבן על Mint או Coral לטקסט קטן.
- אין להציג את תמונת הקמפיין כעדות של לקוח אמיתי.
- צילום AI חייב לעבור בדיקת אנטומיה, אותנטיות וייצוג לפני פרסום.
